# libft

## About the Project

The **libft** project is a foundational 42 School assignment. The goal is to code a basic C library from scratch, reinforcing your understanding of memory management, string operations, and other key aspects of low-level programming.

### Features

- Full reimplementation of key standard C library functions.
- Additional utility functions to ease future projects.
- Bonus section (additional functions and data structures).

## Mandatory Part

You will find reimplementations for standard libc functions, such as:

- String manipulation (`ft_strlen`, `ft_strcpy`, ...)
- Memory handling (`ft_memset`, `ft_memcpy`, `ft_memmove`, ...)
- Character checks (`ft_isalpha`, `ft_isdigit`, ...)
- Conversion functions (`ft_atoi`, ...)
- And many more!

## Bonus Part

Bonus content typically includes:

- Linked lists

## Getting Started

Clone the repository:

```sh
git clone https://github.com/qaneee/libft.git
cd libft
make
```

This will compile the library and produce `libft.a`.

## Usage

Include the header file in your project:

```c
#include "libft.h"
```
